All 30 Cams Layout:
Module 1: GIS Map Infrastructure (Lead 5)
Function 10: Tile Layer Loader BorderMap.tsx

What It Does

Renders base map tiles with automatic fallback between local offline tile packages and public OpenStreetMap servers.

Function 11: Security Zone Overlay MapZonesOverlay.tsx

What It Does

Overlay semi-transparent colored polygons over perimeter areas to define restricted or high-risk sectors.

Function 12: Camera Marker Layer CameraMarkers.tsx

What It Does

Plots interactive camera icons with projected Field-of-View (FOV) vision cones onto the map layer.

Function 13: Live Feed Link Popup MapFeedLink.tsx

What It Does

Connects map nodes to video feeds, opening a modal to trigger direct RTSP video streaming.

Function 14: Patrol Route Layer PatrolRoutes.tsx

What It Does

Displays ground soldier locations and planned movement paths with animated direction dashes.

Function 15: Breach Ping Visualizer BreachPingOverlay.tsx

What It Does

Renders expanding radar pulse rings over intrusion coordinates to alert operators.

Function 16: Journey & Path Tracker JourneyTracker.tsx

What It Does

Connects multi-camera target detections into a chronological path trail for suspect interception.

Function 17: Interactive Layer Controller MapLayerControl.tsx

What It Does

Floating toggle box allowing operators to show/hide specific map layers (tiles, zones, FOV, routes).

Module 2: Alerts & Analytics Interface (Lead 6)
Function 18: Audit Log Stream AuditLogStream.tsx

What It Does

Chronological security event timeline logging motion events, errors, and system warnings in real time.

Function 19: Audio Siren Engine AudioSirenEngine.tsx

What It Does

Generates real-time sound alarms using Web Audio API synthesis without external `.mp3` files.

Function 20: Radar Sweep Gauge RadarSweepGauge.tsx

What It Does

HTML5 Canvas circular radar displaying 360-degree rotating sweeps and target distance blips.

Function 21: System Health Monitor HealthMetricsBar.tsx

What It Does

Displays CPU, memory load, camera network uptime, and API latency metrics.

Function 22: Log CSV Exporter CSVExporter.tsx

What It Does

Converts JSON event logs into downloadable structured `.csv` spreadsheet records.

Function 23: Log Filter Toolbar LogFilterToolbar.tsx

What It Does

Filter control bar to sort security events by severity level, sector, or custom date range.

Function 24: Threat Density Heatmap ThreatHeatmap.tsx

What It Does

Calculates spatial incident density to project green-to-red breach vulnerability overlays.

Function 25: AI Natural Language Query Panel AIQueryPanel.tsx

What It Does

Accepts natural text questions (e.g., *"Show breaches near Sector 4"*) to update system filters.
